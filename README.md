# Katelyn's ART 74 portfolio

A responsive, whimsical editorial-style portfolio built with plain HTML, custom CSS, and a tiny JavaScript file for the mobile navigation. It is designed for GitHub Pages.

## Files
- `index.html` — home page and contact section
- `about.html` — artist statement / biography draft
- `projects.html` — documented work and ART 74 required-project checklist
- `style.css` — responsive layout, typography, colors, and decorative artwork panels
- `script.js` — accessible mobile navigation toggle
- `images/` — replaceable image assets go here

## Before submitting — important
This is a starter portfolio, not yet a final submission. Replace all bracketed factual details and temporary graphic panels with your real work.

1. Update the artist statement in `about.html` so it reflects your own experience, interests, influences, and process.
2. Replace `YOUR-EMAIL@example.com` in `index.html` with an email address you are comfortable sharing, or remove the contact button.
3. In `projects.html`, update each title, year, medium, software, process, and significance to accurately describe the work you made.
4. Add images with these exact names, or update the `src` paths:
   - `images/glitch.jpg`
   - `images/photography.jpg`
   - `images/other-work.jpg`
5. Add the required **2D meme**, **time-based mashup**, and **hypertext** projects. They are listed in the checklist because their actual media and details have not been supplied yet. Use the existing project-entry structure as your guide.
6. For the mashup, upload the video to YouTube as **Unlisted** and embed it with an iframe. Do not upload a large video file to this repository.
7. Test the published site on desktop and mobile. Click every nav link, project link, contact link, and play each embedded video.

## Publish on GitHub Pages
1. Create a repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload the contents of this folder to the repository root (not the outer folder).
3. In the repository, open **Settings → Pages**. Choose **Deploy from a branch**, select `main` and `/ (root)`, and save.
4. Wait for GitHub Pages to finish publishing. Your URL should be `https://YOUR-GITHUB-USERNAME.github.io/`.
5. Open the live URL and test it. If you change files, commit and push the updates.
